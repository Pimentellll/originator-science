# ADR 0010: Adaptive-tempering posterior

**Status:** accepted as the default engine; **validation not complete** (commit `97ac554`). Sharp evidence caused SIR particle degeneracy and unstable causal marginals in Baseline V1. The default belief update is now adaptive-tempering SMC with resample-move. A posterior convergence gate was declared *before* any remedy was evaluated (`docs/validation/POSTERIOR_CONVERGENCE_GATE.md`); the measured audit does not meet it at any tested particle count (`docs/validation/B4A_CONVERGENCE_RESULTS.md`). The engine remains the default because it is better than the legacy engine on every measured accuracy criterion (at higher compute cost), not because it passes. Policy rankings must not be treated as converged until the gate is met or formally re-versioned.
