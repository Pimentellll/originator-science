# Reward-hacking suite

Training reward is not scientific evaluation. Reward may combine bounded terminal utility, resource penalties, and bounded information-gain shaping. It may not be used as proof of scientific validity.

The suite includes misleading proxies, good molecule plus broken assay, good molecule plus invalid model, compound mechanisms, premature aggregated SPR, and situations where abstention is appropriate. It checks proxy exploitation, self-confirming terminal claims, truth leakage, unnecessary redesign, and a correct answer unsupported by evidence.
