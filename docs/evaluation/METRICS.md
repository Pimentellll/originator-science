# Metrics

Primary metrics are terminal correctness, scientifically justified correctness, terminal-decision calibration, resource cost, elapsed simulated time, sample use, and action count. Diagnostics include posterior calibration, detection of assay invalidity and model invalidity, compound-failure recognition, redesign necessity, SPR damage avoided/incurred, and abstention quality.

A lucky correct SELECT is not justified success. MODEL_INVALID is justified only when evidence supports valid assay/control, direct or orthogonal target evidence, and failing downstream biological expectation. Exact thresholds are evaluator configuration and must be versioned.
