# Factorised causal state

Private BinderHiddenState is factorised, not a one-of-W1-W8 class:

| Factor | Interpretation |
| --- | --- |
| folding/stability | structural robustness |
| monomer fraction | aggregation tendency |
| log KD | equilibrium affinity |
| log koff | dissociation kinetics |
| functional epitope | target engagement relevance |
| developability liability | off-target or developability risk |
| assay validity | downstream assay integrity |
| biological-model validity | pathway/translation assumption integrity |

A scenario template may set one or more factors to a failure regime; it does not replace the factorised representation. Resource state is separate: budget, sample, simulated time, SPR health, candidate generation, and lineage. Truth belongs solely to the environment and privileged evaluator.
