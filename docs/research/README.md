| [BIOLOGICAL_IDENTIFIABILITY_RESEARCH.md](BIOLOGICAL_IDENTIFIABILITY_RESEARCH.md) | **Research and context. Not implemented.** A literature-style monograph on biological identifiability, mechanistic ambiguity and optimal experimental disambiguation, proposing seven candidate systems-biology benchmark systems (MAPK, I1-FFL vs NFBLB, enzyme kinetics, toggle switch, GPCR biased agonism, apoptosis threshold, p53/NF-κB). None of these systems exists in this repository. |

The note motivates the design principle that interventions, not passive observation, disambiguate mechanisms, and that an
agent should recognise intrinsic unidentifiability. Its citations and quantitative statements have **not** been verified
as part of this repository's documentation audit, and it refers to the original growth benchmark as `MIRAGE-Bio v0.1`.
Nothing in it is a result of this project. It does not describe the Binder BioPOMDP.
